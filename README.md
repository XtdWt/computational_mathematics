## Setup
<p>Current set up for this project is with `uv` and `maturin`</p>
<p>Steps: </p>
<ul>
    <li>`pip install uv`</li>
    <li>`uv tool install maturin`</li>
    <li>`maturin develop` or `maturin develop -r`</li>
</ul>
<p>Tests can be run with `cargo test` for rust tests and `pytest` for python tests.</p>
