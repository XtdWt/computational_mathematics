## Setup
Current set up for this project is with `uv` and `maturin`
Steps: 
- `pip install uv`
- `uv tool install maturin`
- `maturin develop` or `maturin develop -r`
<p>Tests can be run with `cargo test` for rust tests and `pytest` for python tests.</p>
